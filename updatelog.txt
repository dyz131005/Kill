Kill Minecraft Launcher 更新日志

============================================================

v2.0  (2026-10-29)
------------------------------------------------------------
- 新增游戏崩溃诊断：游戏异常退出时自动弹出 HMCL 风格崩溃窗口，隐藏主窗口
- 崩溃窗口内置正则原因分析（Java 版本/内存/显卡/模组冲突等），支持复制日志、打开日志文件夹、导出崩溃报告、返回启动器
- 默认存储位置改为安装目录下的 .kill（配置/插件/Java/临时文件），设置里可切换 AppData 或自定义目录
- 存储位置支持「识别旧路径」与「一键迁移」，方便从旧版本迁移数据
- 设置页新增「存储位置」区块，可应用并持久化新的存储目录
- 插件管理页新增「安装插件」：支持点击选择 DLL，或把 DLL 直接拖进列表安装；同名文件会询问是否覆盖
- 修复标签页切换动画的坐标串轴/离顶问题，重做为截图浮层 + 动画 pos 的方案，并新增上下切换的垂直滑动
- 关闭窗口改为整个窗口向上滑出屏幕后再退出
- 崩溃窗口由普通窗口改为模态对话框，修复按钮点击无反应与系统警告音的问题
- 修复崩溃原因卡片样式级联导致内部文字出现方框、行距过紧的问题
- 设置页内容超出一屏时不可滚动的问题修复（后续如需可继续完善）
- README 全面更新：补充插件系统、并发下载、崩溃诊断、动画、存储位置等新特性与最新目录结构
- 版本号更新为 2.0

v1.9  (2026-10-29)
------------------------------------------------------------
- 下载界面重做为 HMCL 风格：窗口内半透明遮罩面板替代独立弹窗，只有「取消」可点
- 新增并发多线程下载引擎：默认 8 并发，逐文件细进度条、完成即消失、顶部总进度条 + 已完成计数
- 修复安装版本时 assets/objects 资源对象不下发、只能启动时补全的问题（预取资源索引后再排任务）
- 启动流程也改为内嵌遮罩面板，并实时显示依赖库/资源补全的逐文件进度
- 启动页新增选中版本头卡（版本图标 + 大号版本名 + 加载器类型）
- 设置新增「界面动画」三档：完全开启 / 部分（仅淡入淡出）/ 完全关闭
- 新增平滑过渡动画：标签页左右滑动、页面淡入淡出、窗口关闭时向上滑出、按钮点击回弹
- Java 运行时自动安装的进度窗口同样改为内嵌遮罩面板
- 版本号更新为 1.9

v1.8  (2026-10-27)
------------------------------------------------------------
- 新增原生 DLL 插件系统：扫描 plugins/ 加载插件，分级权限（安全/需确认/禁止）
- 插件 UI 注入能力：注入全局样式、控件、按钮、设置项、覆盖页面
- 新增插件管理页：列出插件、显示权限、授权/取消授权
- 插件事件钩子：app.startup / game.before_launch / game.after_exit
- 新增开源合规：LGPLv3/GPLv3 协议、第三方声明、RELINKING 重链接说明
- 仓库附带静态 Qt 源码压缩包与 Win7 兼容补丁（qt-static-src/）
- 关于页面版本号更新为 1.8

v1.7  (2026-10-26)
------------------------------------------------------------
- Win7 RTM(7600 无 SP1) 兼容性修复，可在 VMware 虚拟机内运行
- 修复 socket 创建时 WSA_FLAG_NO_HANDLE_INHERIT 在 Win7 上导致 Protocol type not supported
- 内置 Mozilla CA 证书库，修复 Win7 旧证书库导致的 SSL 自签名/不受信任握手失败
- 原生库/JRE/整合包解压改用内置 QZipReader，不再依赖系统 tar / PowerShell
- 修复无 url 字段的旧库(如 launchwrapper)未下载导致找不到主类
- 修复缺少 -cp 参数导致老版本(pre-1.6)找不到主类
- 修复缺少 -Djava.library.path 导致 lwjgl 找不到原生库
- 支持 Mesa 软件 OpenGL：自动设置 GALLIUM_DRIVER 等环境变量并加 allowSoftwareOpenGL 参数
- 关于页面版本号更新为 1.7

v1.6  (2026-10-25)
------------------------------------------------------------
- 主编译切换为静态 Qt 单文件构建（默认 KILL_STATIC_QT=ON），产物直接输出到 dist 目录
- 取消 Inno Setup 安装程序打包流程，删除 build.iss，dist 内仅保留 Kill.exe 与 icon.ico
- 构建产物不再携带 Qt 运行库 DLL / 插件，单文件即可运行
- 新增 Win7 兼容处理：编译后自动修补静态 CRT 硬链接的 GetSystemTimePreciseAsFileTime 导入，改用 Win7 可用的 GetSystemTimeAsFileTime
- 更新日志改为内嵌进 exe 资源（resources.qrc），关于页面直接从 :/updatelog.txt 读取，不再依赖外部文件
- 移除 README 底部免责声明
- 关于页面版本号更新为 1.6

- 实例卡片显示类型图标、实例名称与状态（当前选中 / 已安装），右侧箭头按钮，底部 1px 分隔线，选中态浅蓝背景
- 实例列表支持关键字搜索过滤，选中项与版本下拉双向同步
