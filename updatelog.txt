Kill Minecraft Launcher 更新日志

============================================================

v1.4  (2026-10-22)
------------------------------------------------------------
- 下载版本页面按 HMCL 重构：顶部工具卡片（搜索框 + 类型筛选 + 刷新按钮同处一行）
- 版本列表改为整宽单列布局，每项显示类型图标、版本号与发布时间两行信息
- 类型筛选对齐 HMCL 五类：正式版 / 快照版 / 愚人节版 / 远古版 / 所有版本，默认选中正式版
- 图标按 HMCL 规则映射：正式版草方块、快照命令方块、远古工作台、愚人节南瓜
- 新增加载中 / 加载失败两种状态页，失败页支持点击重试
- 安装流程改为内嵌页面，不再弹出独立对话框；左上角提供返回按钮
- 点击版本列表项直接进入安装页，页面内可修改实例名称并确认安装
- 关于页面版本号更新为 1.4

v1.3  (2026-10-21)
------------------------------------------------------------
- 下载版本页面全面重做，参考 HMCL 逻辑与 UI：左侧版本列表 + 右侧版本详情卡片
- 版本列表按类型显示对应图标（正式版草方块 / 快照工作台 / 远古熔炉 / 愚人节 / 各加载器等），图标资源随程序打包
- 新增版本号搜索框，支持类型筛选 + 关键字实时过滤
- 右侧详情卡片展示大图标、版本号、类型、发布时间，并提供「安装此版本」按钮，双击列表项也可直接安装
- 打包附带 OpenSSL 运行库（libssl / libcrypto），修复部分 HTTPS 下载场景下提示缺失 libssl 的问题
- dist 目录附带 icon.ico，安装包快捷方式可正常引用图标
- 可执行文件本身嵌入自定义图标与版本信息（Windows RC 资源），任务栏 / 资源管理器 / 属性页均正确显示
- 关于页面版本号更新为 1.3

v1.2  (2026-10-20)
------------------------------------------------------------
- 新增顶部公告栏，常驻展示关于下载功能的立场声明，支持一键收起，明暗主题自动适配
- 新增「反对恶意举报」严正公告：坚决反对个别人士的恶意举报行为，该行为严重破坏 MC 社区繁荣发展
- 重申承诺：绝不下架、绝不关闭任何下载功能，版本 / 模组 / 整合包 / 资源包 / 数据包下载永久保持开放
- README 同步更新公告内容
- 关于页面版本号更新为 1.2

v1.0  (更早版本)
